راه‌اندازی خودکار رله اختصاصی کلودفلر و اتصال مستقیم به ۹روتر و هرمس با دور زدن تحریم‌های گوگل، جمینای، آنتی‌گراویتی و کلود.

راه‌اندازی با ۱ دستور در ترمینال

کلید کلودفلر را وارد کنید تا دستور اختصاصی سیستم شما آماده شود:

تنظیم خودکار در ۹روتر
ساده‌ترین روش بدون پر کردن هیچ گزینه‌ای: مشاهده Global API Key در کلودفلر ↗

وارد لینک بالا شوید، پایین صفحه روبروی Global API Key دکمه View را بزنید، پسورد اکانت را وارد کرده و کلید را کپی و اینجا پیست کنید:

🔗 ورود به صفحه ساخت توکن کلودفلر ↗

۱ در لیست تمپلیت‌ها، روبروی ردیف چهارم Edit Cloudflare Workers دکمه آبی Use template را بزنید.

۲ در بخش Account Resources نام اکانت خود را انتخاب کنید.

۳ در بخش Zone Resources گزینه را به All zones تغییر دهید.

۴ پایین صفحه دکمه Continue و Create Token را زده و توکن را کپی کنید.
