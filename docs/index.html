روش ۱: راه‌اندازی خودکار با ۱ دستور (پیشنهادی)

بدون ریستارت سیستم
ساده‌ترین راه بدون انتخاب هیچ گزینه‌ای: مشاهده Global API Key ↗

وارد لینک بالا شوید، پایین صفحه روبروی Global API Key دکمه View را بزنید، پسورد اکانت را وارد کرده و کلید را کپی و اینجا پیست کنید:

🔗 صفحه ساخت توکن کلودفلر ↗

با کلید گلوبال، رکوردهای DNS و Route به صورت ۱۰۰٪ خودکار توسط اسکریپت ساخته خواهند شد.

            🛠️ روش ۳: کپی دستی کد در پنل کلودفلر
          

          
مناسب کسانی که نمی‌خواهند هیچ کلید یا توکنی در برنامه یا اسکریپت وارد کنند:

        

        بدون توکن
      


      

        
۱. وارد داشبورد کلودفلر شوید: dash.cloudflare.com

        
۲. از منوی سمت چپ به Workers & Pages بروید و دکمه Create Application > Create Worker را بزنید.

        
۳. یک نام دلخواه بگذارید (مثلاً `hermes-cloud-relay`) و دکمه Deploy و سپس Edit Code را بزنید.

        
۴. کدهای داخل ادیتور را پاک کنید و کدهای رسمی زیر را کپی کرده و پیست کنید، سپس Save and deploy را بزنید:

      


      

        
export default {
  async fetch(request, env, ctx) {
    const target = request.headers.get("x-relay-target");
    const relayPath = request.headers.get("x-relay-path") || "/";

    if (!target) {
      return new Response(JSON.stringify({ error: "Missing x-relay-target header" }), {
        status: 400,
        headers: { "content-type": "application/json" },
      });
    }

    const targetUrl = target.replace(/\/$/, "") + relayPath;
    const newRequestInit = {
      method: request.method,
      headers: new Headers(request.headers),
    };

    if (request.method !== "GET" && request.method !== "HEAD") {
      newRequestInit.body = request.body;
      newRequestInit.duplex = "half";
    }

    newRequestInit.headers.delete("x-relay-target");
    newRequestInit.headers.delete("x-relay-path");
    newRequestInit.headers.delete("host");

    try {
      const response = await fetch(targetUrl, newRequestInit);
      return new Response(response.body, {
        status: response.status,
        headers: response.headers,
      });
    } catch (error) {
      return new Response(JSON.stringify({ error: error.message }), {
        status: 502,
        headers: { "content-type": "application/json" },
      });
    }
  },
};
