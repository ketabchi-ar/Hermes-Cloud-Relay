⚡ درگاه هوشمند هوش مصنوعی سرورلس و رایگان

اتصال بدون فیلترشکن به هوش مصنوعی

راه‌اندازی خودکار رله اختصاصی کلودفلر و اتصال مستقیم به ۹روتر و هرمس با دور زدن تحریم‌های گوگل، جمینای، آنتی‌گراویتی و کلود.

ویزارد راه‌اندازی ۱-کلیکی

روش احراز هویت با کلودفلر را انتخاب کنید:

بدون نیاز به ریستارت
ساده‌ترین راه بدون پر کردن هیچ فرمی: مشاهده Global API Key در کلودفلر ↗

کافی است وارد لینک بالا شوید، در پایین صفحه روبروی عبارت Global API Key دکمه View را بزنید، پسورد اکانت را وارد کرده و کلید را کپی و اینجا پیست کنید:

🔗 ورود به صفحه ساخت توکن کلودفلر ↗

۱ روی لینک بالا کلیک کنید.

۲ در لیست تمپلیت‌ها، روبروی ردیف چهارم Edit Cloudflare Workers دکمه آبی Use template را بزنید.

۳ در بخش Account Resources کادر قرمز را باز کرده و نام اکانت خودتان را انتخاب کنید.

۴ در بخش Zone Resources کادر دوم را از Specific zone به All zones تغییر دهید.

۵ پایین صفحه دکمه آبی Continue to summary و سپس Create Token را بزنید و توکن را کپی کنید. 


        

        

          ⚡ نحوه اجرا: دستور بالا را کپی کنید، در ترمینال (یا PowerShell ویندوز) Paste کنید و اینتر بزنید. کل مراحل ساخت ورکر، ساب‌دامنه و اتصال به ۹روتر در ۱۰ ثانیه خودکار انجام می‌شود!
